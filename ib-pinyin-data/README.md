# ib-pinyin-data
[![crates.io](https://img.shields.io/crates/v/ib-pinyin-data.svg)](https://crates.io/crates/ib-pinyin-data)
[![Documentation](https://docs.rs/ib-pinyin-data/badge.svg)](https://docs.rs/ib-pinyin-data)
[![License](https://img.shields.io/crates/l/ib-pinyin-data.svg)](../LICENSE.txt)

A fast and multi-notation Chinese pinyin query library.

See [Pinyin](https://en.wikipedia.org/wiki/Pinyin) for what is pinyin.

## Features
- 支持以下拼音编码方案：
  - 简拼（“py”）
  - 全拼（“pinyin”）
  - 带声调全拼（“pin1yin1”）
  - Unicode（“pīnyīn”）
  - 智能 ABC 双拼
  - 拼音加加双拼
  - 微软双拼
  - 华宇双拼（紫光双拼）
  - 小鹤双拼
  - 自然码双拼
- 支持多音字。
- 支持 Unicode 辅助平面汉字。
